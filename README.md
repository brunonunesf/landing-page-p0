# Brasileirão 2026 — Séries A e B

Landing page responsiva com as classificações do Campeonato Brasileiro Séries A e B, congeladas em 17 de outubro de 2026.

## Recursos

- alternância entre Série A e Série B;
- escudos oficiais dos clubes;
- retrospecto dos últimos cinco jogos;
- próximos confrontos e mando de campo;
- artilheiros, assistências e jogadores mais valiosos;
- valores de mercado dos elencos;
- links para notícias e prévias;
- modos claro e escuro;
- layout adaptado para computador e celular.

## Executar localmente

Abra `index.html` no navegador ou sirva a pasta com um servidor HTTP estático.

## Fontes

ge, CBF, ESPN, Brasileirão 360 e Transfermarkt. A página informa o recorte e as fontes no rodapé.
